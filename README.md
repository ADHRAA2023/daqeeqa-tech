# دقيقة تقنية — مدرسة الصراط

## نشر الموقع على GitHub Pages
1. فك ضغط ZIP.
2. أنشئ مستودع GitHub جديدًا (عامًا إذا أردت استخدام GitHub Pages مجانًا).
3. ارفع **محتويات المجلد** إلى جذر المستودع، خصوصًا `index.html` (وليس ملف ZIP نفسه).
4. من Settings > Pages اختر Deploy from a branch، ثم main و / (root)، واحفظ.
5. افتح رابط Pages بعد اكتمال النشر.

## تجربة لوحة التحكم
اضغط «الإدارة» ثم «الدخول للتجربة المحلية». يمكنك إضافة البرامج وتعديلها، لكن التعديلات تُحفظ في المتصفح نفسه فقط، وليست مشتركة بين الزوار. هذا الوضع **ليس محميًا بكلمة مرور** ولا يناسب النشر الإداري الحقيقي.

## تفعيل قاعدة بيانات مشتركة ولوحة تحكم آمنة
1. أنشئ مشروعًا في https://supabase.com.
2. افتح SQL Editor ونفّذ محتويات `database.sql`.
3. من Authentication > Users أنشئ حساب المشرفة، وانسخ User UUID.
4. نفّذ في SQL Editor: `insert into public.admins(user_id) values ('UUID-HERE');` بعد استبدال UUID-HERE.
5. من إعدادات Supabase انسخ Project URL و **publishable key** أو **anon key** (لا تستخدم secret/service_role key).
6. افتح الموقع، ثم «الإدارة»، وأدخل URL والمفتاح العام، واضغط «تفعيل الاتصال».
7. سجّلي الدخول بالبريد وكلمة المرور. أي تغيير في البرامج يظهر لجميع الزوار بعد الحفظ.

**مهم:** بعد تفعيل Supabase تكون قائمة البرامج فارغة حتى تضيفي البرامج عبر لوحة الإدارة؛ بيانات البرامج الـ12 موجودة مبدئيًا في وضع العرض المحلي فقط. يمكنك إضافة البرامج في لوحة الإدارة السحابية.

**الشعارات:** رفع الشعار في النسخة الحالية يحفظه محليًا على الجهاز فقط. لجعل الشعار ظاهرًا للجميع، ضعي صورة في المستودع وعدّلي `index.html` ليشير إليها، أو طوّري رفع الصور باستخدام Supabase Storage.

**الفيديوهات:** ضعي رابط فيديو يوتيوب في حقل الفيديو لكل برنامج.

## ملاحظات
- GitHub Pages يستضيف ملفات الموقع الثابتة، ولا يشغّل قاعدة بيانات بمفرده.
- لا تضعي مفاتيح سرية أو كلمات مرور في ملفات GitHub.
- تسجيل الدخول الآمن والتحكم في الصلاحيات يتمان عبر Supabase Auth وRow Level Security.
